# Datasets

Set `YOLOX_DATADIR` to the directory that contains your datasets, or place them under `./datasets` (the default):

```shell
export YOLOX_DATADIR=/path/to/your/datasets
```

---

## EMT

Expected layout after running `emt_to_coco.py`:

```
$YOLOX_DATADIR/EMT/
├── frames/                            # training images
│   └── video_XXXXXX/
│       └── frame_XXXXXX.jpg
├── test_frames/                       # test images (same structure)
└── annotations/
    └── detections_new/
        ├── train_3class.json          # generated by emt_to_coco.py
        └── test_3class.json
```

Convert KITTI-style labels before the first training run:

```shell
python tools/support_scripts/emt_to_coco.py
```

The experiment file reads from `annotations/detections_new/` by default. Override via `self.annotation_dir` in the exp file.

## ROAD Waymo

Expected layout after running `road_to_coco.py`:

```
$YOLOX_DATADIR/road_waymo/
├── train_frames/                      # all frames (shared by train and val splits)
│   └── train_XXXXX/
│       └── XXXXX.jpg
├── road_waymo_trainval_v1.0.json      # original source annotations (not used at training time)
└── road_waymo_annotations/
    ├── train_3class.json              # generated by road_to_coco.py --preset emt
    └── val_3class.json
```

Convert to 3-class COCO JSON:

```shell
python tools/support_scripts/road_waymo_tool.py merge --split train --preset emt \
    --out datasets/road_waymo/road_waymo_annotations/train_3class.json

python tools/support_scripts/road_waymo_tool.py merge --split val --preset emt \
    --out datasets/road_waymo/road_waymo_annotations/val_3class.json
```

The experiment file reads from `road_waymo_annotations/` by default.

## Class taxonomy (EMT and ROAD Waymo)

Both datasets use the same 3-class scheme:

| ID | Name | Source categories |
|----|------|------------------|
| 1 | VulnerableRoadUser | Pedestrian, Cyclist |
| 2 | Two-Wheeler | Motorbike, Small_motorised_vehicle |
| 3 | Vehicle | Car, Bus, Medium_vehicle, Large_vehicle, Emergency_vehicle |

## Generic COCO datasets (upstream YOLOX)

For standard COCO training, place or symlink the dataset at:

```
$YOLOX_DATADIR/COCO/
├── annotations/
│   ├── instances_train2017.json
│   └── instances_val2017.json
├── train2017/
└── val2017/
```
